SummitDesk v45 — Seven-day forecast date navigation
Prerequisite: v44 installed and working.
Run from the project root: python3 v45_package/install_v45.py
Date range: today through 365 days ahead. Invalid/out-of-range dates revert to today.
Manager-only: no new endpoint, uses existing authorized Staff Hub.
Forecast CSV exports selected date window. Alert computations stay based on today.
No migrations. Backups are created before modifications.
